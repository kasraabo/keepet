# کیپت · نقطهٔ شروع توسعه

مارکت‌پلیس curated مراقبت از حیوانات خانگی در تهران: **مشاورهٔ آنلاین دامپزشکی، گرومینگ و نمونه‌برداری ساده در منزل**. هر رزرو پس از پیش‌پرداخت به صف عملیات می‌رود؛ زمان دقیق با هماهنگی انسانی تعیین می‌شود.

این نسخه **MVP توسعهٔ قابل اجرا** است: کد ورود روی صفحه نمایش داده می‌شود، پرداخت و بازگشت وجه آزمایشی‌اند و ارائه‌دهندگان دادهٔ نمونه هستند. گفتگوی دامپزشک و مشتری با متن، تصویر و پیام صوتی داخل سایت انجام می‌شود؛ مدت پیش‌فرض آن ۳۰ دقیقه و قابل تنظیم است و سپس پروندهٔ خصوصی آن باقی می‌ماند. سرویس‌های کاوه‌نگار، زرین‌پال، n8n و تماس خارجی هنوز متصل نشده‌اند. تماس صوتی زنده و ویدیو ساخته نشده‌اند. اجرای `APP_MODE=production` عمداً متوقف می‌شود تا ورود و پرداخت آزمایشی به محیط واقعی راه پیدا نکنند.

## اجرا

Go 1.26.9، PostgreSQL 17 و Docker نیاز هستند. در محیط cloud، بدون ایجاد worktree از همین checkout استفاده کنید.

```bash
cd /workspace/keepet
make setup  # نصب Go با بررسی SHA256، دریافت ماژول‌ها و آماده‌سازی Postgres
make run    # اجرای وب روی پورت 8080؛ مهاجرت‌ها و داده‌های نمونه در startup
```

برای ماشین شخصی با Docker: `docker compose up --build`. این مسیر محیط **توسعه** است. Docker روی localhost پورت 8080 را منتشر می‌کند. برای تغییر پورت یا اتصال به Postgres دیگر، `PORT` و `DATABASE_URL` را در محیط ست کنید. `.env.example` صرفاً مرجع است و به‌صورت خودکار خوانده نمی‌شود.

## مسیرهای اصلی

| صفحه | مسیر |
|---|---|
| خانه و خدمات | `/`، `/services/vet`، `/services/grooming`، `/services/sampling` |
| ورود / ثبت‌نام | `/login` |
| حساب، رزروها و پت‌ها | `/dashboard` |
| صف عملیات، بازه‌ها، همکاری و تیکت‌ها | `/ops` |
| کارهای ارائه‌دهنده | `/provider` |
| گفتگوهای ویزیت و پروندهٔ خصوصی مشتری/دامپزشک | `/chats` |
| مدیریت کسب‌وکار (قیمت، عرضه، مالی، تریاژ، محتوا، audit) | `/management` |
| گفتگوها و تنظیم مدت در مدیریت | `/management/chats` |
| درخواست همکاری | `/join` |
| راهنما و پشتیبانی | `/support` |
| سلامت برنامه و دیتابیس | `/health` |

در صفحهٔ ورود، شمارهٔ معتبر وارد کنید و کد نمایش‌داده‌شده را استفاده کنید. حساب‌های ویژهٔ **صرفاً توسعه**:

| نقش | شماره |
|---|---|
| عملیات | `09120000001` |
| دامپزشک نازنین | `09120000002` |
| گرومر | `09120000003` |
| نمونه‌بردار | `09120000004` |
| مدیر | `09120000005` |
| دامپزشک جایگزین | `09120000006` |

برای صاحب حیوان از هر شمارهٔ معتبر دیگر استفاده کنید. نقش دلخواه از فرم ورود قابل انتخاب نیست. برای دیدن هم‌زمان پنل‌ها، از پروفایل‌های مجزا یا پنجرهٔ خصوصی مرورگر استفاده کنید.

برای آزمایش گفتگو، مشتری رزرو دامپزشکی را پرداخت می‌کند؛ عملیات زمان و متخصص را هماهنگ و تخصیص می‌دهد و دامپزشک در پنل خود کار را می‌پذیرد و شروع می‌کند. «خروج و تکمیل فرم» پرسشنامهٔ همان فرد را باز می‌کند؛ «پایان ویزیت» یا انقضای زمان، ارسال پیام را برای هر دو می‌بندد. پرونده، تصویرها، صدا و فرم‌ها در PostgreSQL ذخیره و پس از restart حفظ می‌شوند. [راهنمای گفتگو و پرسشنامه‌ها](docs/consultation-chat.md).

متخصص می‌تواند ساعت شروع و پایان دلخواه ثبت کند؛ مدیریت هنگام تخصیص از همان بازه‌های واقعی دارای ظرفیت انتخاب می‌کند. [راهنمای زمان‌های کاری](docs/availability.md).

## استک و تست

Go + `net/http`، pgx، PostgreSQL، `golang-migrate`، پوستهٔ templ و صفحات `html/template`، HTMX و Alpine؛ بدون SPA. همهٔ فونت‌ها، اسکریپت‌ها و تصویرهای SVG محلی‌اند. رابط فارسی RTL، تاریخ نمایشی جلالی در منطقهٔ تهران و PWA با کش صرفاً فایل‌های عمومی.

```bash
make test     # تست واحد، یکپارچه PostgreSQL، race detector و go vet
make generate # بازتولید پوستهٔ templ؛ فایل generated در ریپو موجود است
```

تست یکپارچه دیتابیس جداگانهٔ `keepet_test` را بازنشانی می‌کند؛ نام دیتابیس حتماً باید پسوند `_test` داشته باشد. تست شامل مسیر کامل سه خدمت، ظرفیت هم‌زمان، قیمت سمت سرور، مالکیت، CSRF، OTP، جایگزینی و کنسلی است. راهنمای تست مرورگر در [تست و اعتبارسنجی](docs/testing.md) است.
