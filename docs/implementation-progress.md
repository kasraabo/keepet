# وضعیت اجرای سند اصلاحات جدید

این فهرست مربوط به متن نهایی اصلاحات و توافق‌های همین پروژه است. `roadmap.md` سابق، شرح نسخهٔ اولیه است و مرجع وضعیت این اصلاحات نیست. مواردی که از فهرست نهایی حذف شده‌اند، صرفاً به دلیل حضور در یادداشت قدیمی به محدوده برنمی‌گردند.

| مرحله | وضعیت کد | راهنما |
|---|---|---|
| درخواست → تأیید اختیاری اپراتور برای هر متخصص → تأیید متخصص → پرداخت؛ مهلت و یادآوری محلی | انجام شده، نصب عمومی نشده | [تأیید درخواست](booking-approval.md) |
| روز شمسی، بازه و ساعت دقیق؛ مدت خدمات و ظرفیت مشترک؛ پیشنهاد زمان نزدیک | انجام شده، نصب عمومی نشده | [زمان‌بندی](exact-scheduling.md) |
| کد حضور، تأیید پایان گرومینگ/مهلت بدون اعتراض، رسید نمونه و تأیید اپراتور؛ شرط درآمد پزشک و معرف | انجام شده، نصب عمومی نشده | [حضور و پایان خدمت](service-fulfillment.md) |
| کاتالوگ آزمایشگاه و پکیج، دستمزد نمونه‌بردار، تفکیک هزینهٔ آزمایشگاه، نتیجهٔ خصوصی و انتشار اپراتور | انجام شده، نصب عمومی نشده | [آزمایشگاه](laboratory.md) |
| چت خدمات حضوری پس از پرداخت، پیام‌های خوانده‌نشده، اعلان‌های سفارش و بازگشت مشتری به رزروها | انجام شده، نصب عمومی نشده | [چت و اعلان](coordination-notifications.md) |
| پیشنهاد جلسه و خدمت بعدی توسط پزشک، ادامه با همان پت، زمان نزدیک و قیمت تازه | انجام شده، نصب عمومی نشده | [ادامهٔ مراقبت](care-followups.md) |
| مسیر ورود متخصص، حفظ نام و رزرو، مدارک خصوصی دامپزشک و ورود گوگل با اتصال امن موبایل | کد و تست انجام شده؛ گوگل نیازمند تنظیمات بیرونی، نصب عمومی نشده | [ورود و ثبت‌نام](auth-onboarding.md) |
| Keepet Mag ویدئویی، چیدمان انتخابی، پیش‌نویس و پیش‌نمایش، رسانهٔ خصوصی و سئوی متن/ویدئو | انجام شده، نصب عمومی نشده | [محتوا و سئو](editorial-mag-seo.md) |
| زیرخدمات و صفحات مرتبط، صف عملیات قابل جست‌وجو، تماس عمومی، کیبورد فارسی و سن تقریبی | انجام شده، نصب عمومی نشده | [مدیریت خدمات و رابط](service-management-interface.md) |
| اعلان‌های کیف پول، برداشت و شبا، تیکت و تحریریه؛ دسترسی جاری و پیگیری مستقیم | انجام شده، نصب عمومی نشده | [اعلان‌های حساب و محتوا](account-notifications.md) |
| جمع‌بندی تست‌ها، بررسی ارتقای تاریخی، ابزار نصب و بازگشت هماهنگ | آماده‌سازی و بررسی محلی؛ نصب عمومی و سرویس‌های واقعی باقی است | [آمادگی نسخه و بازگشت](release-readiness.md) |

کارهای بیرونی باقی‌مانده:

- اتصال و تأیید پیامک/درگاه واقعی، تنظیم Google، تکمیل داده‌های واقعی و نصب نسخهٔ انتخاب‌شده روی آروان.

بعضی زیرقابلیت‌های این بسته‌ها از قبل وجود دارند؛ در شروع هر مرحله ابتدا وضعیت واقعی بررسی می‌شود تا کار انجام‌شده دوباره ساخته نشود. پیامک و درگاه واقعی هنوز متصل نیستند. داشتن outbox یا پرداخت آزمایشی به معنی ارسال پیامک یا دریافت پول واقعی نیست.
